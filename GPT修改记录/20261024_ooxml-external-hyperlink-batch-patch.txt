## 修改目的

避免按 Audit Issue 逐条调用单条 OOXML 超链接补丁导致整本 XLSX 重复读写；为工作簿提供一次提交多条超链接的批量 API。

## 修改文件与行为

- `crates/ooxml-patch/src/lib.rs`：新增 `patch_external_hyperlinks(source, candidate, &[ExternalHyperlinkPatch])`；单条 `patch_external_hyperlink` 保留为批量 API 包装。按 workbook relationship 一次解析 sheet identity，按 sheet 分组，每个目标 worksheet 和 rels 部件只读取/解析一次；整批预检所有单元格和关系映射后才创建输出。不同 hyperlink 不得共享 relationship id，避免修改一个 target 意外影响未选中的链接。所有条目通过后仅进行一次 ZIP 输出和一次包级回读验证。任何映射失败都不会创建候选文件。源文件不变，拒绝覆盖既有输出。
- 增补合成测试：同一 sheet 多目标、跨 sheet 批量、TargetMode 与 display/location 读回、多部件保留、某项缺失时无候选输出、源文件不变；单条 API wrapper 与歧义映射测试继续通过。
