# 外汇页眉文本 Rust 候选迁移

日期：2026-10-23

## 目的与范围

将 pytools `feature_1_4_fx_header.py` 的窄业务操作接入 workspace 共享边界：扫描工作表名含“外汇”的 sheet，把 odd/even/first 页眉左右中各段的“万元”替换为“万美元”。只接受 `.xlsx` 候选，不接菜单、不覆盖源文件、不变更默认路由。

本轮确认 PyCode 与 NoComPyTools 对应源文件内容相同，SHA-256 均为 `CC436A215D577F6063CC1847024F890448711D22278BCF07EFF7088452E0E00E`。源项目保持只读。

## 修改文件

- `crates/excel-reader/src/lib.rs`：新增关系解析驱动的 odd/even/first 页眉文本读取 API；拒绝嵌套富文本，避免以不完整投影参与业务判定；新增非标准 workbook part 与 chartsheet 排除测试。
- `crates/ooxml-patch/src/lib.rs`：修改 worksheet 解析，从 `_rels/.rels` 定位 workbook，再从 workbook relationships 定位 worksheet；既有补丁路径不再固定假设 `xl/workbook.xml`。增加自定义 part 位置测试，并补齐符合 OOXML 的根/工作表关系测试夹具。
- `pytools-core/src/fx_header.rs`：计划构建器改用 `excel-reader` 公共读 API，不再直接调用 patch reader。
- `pytools-core/tests/fx_header_parity.rs`：验证 Python 基线统计、三种页眉、非目标 sheet、值/公式/合并/批注/条件格式/数据验证、补丁范围及 Calamine 重开；支持通过 `PYTOOLS_FX_HEADER_PARITY_REPORT` 显式生成机器报告。
- `pytools-core/probe/reports/fx_header_parity.json`：本轮专项对拍机器报告。
- `EXCEL_ENGINE_ARCHITECTURE.md`、`PYTHON_EXCEL_OPERATION_INVENTORY.md`、`pytools-core/MIGRATION_INVENTORY.md`：登记源操作、候选路径、能力矩阵和未验收边界。

## 当前能力与未完成项

对拍仅覆盖一份合成 `.xlsx`。候选还未接入菜单/CLI 或真实批量文件调度；未实现原 Python 的源路径替换语义；真实业务工作簿、`.xlsm`/VBA、Windows 原生 Rust、麒麟/UOS glibc 2.28、deb 与性能/峰值内存均未验收。不得将此候选登记为产品默认或完整菜单迁移。

Patch 明确拒绝签名包、宏包及嵌套页眉标记；当前只有一个合格后端，失败不会继续在中间产物上处理。跨引擎备选必须从原始输入重新执行并重新验收。

## 回退

不接入 dispatcher，继续保留旧 Python 菜单功能。若后续拒绝该候选，只撤回上述 Rust 候选、共享 adapter、专项报告和对应清单记录；不清理或重置 workspace 其他未提交/未跟踪内容，也不改动原 Python 项目。
