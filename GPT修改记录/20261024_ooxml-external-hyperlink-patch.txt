## 修改目的

为 Rust 生成 XLSX 后的绝对文件 hyperlink relationship 修复提供通用 `ooxml-patch` 原语，避免 Audit 直接维护 ZIP/XML 补丁。

## 修改文件与行为

- `crates/ooxml-patch/src/lib.rs`：新增 `ExternalHyperlinkPatch`、`ExternalHyperlinkPatchReport` 和 `patch_external_hyperlink(source, output, patch)`。根据 workbook sheet identity 定位 worksheet，再按规范化单元格坐标要求唯一 `<hyperlink>`；通过其 `r:id` 在该 worksheet 的 relationships part 中要求唯一 `/hyperlink` relationship。只更新对应 relationship 的 `Target` 与 `TargetMode="External"`，可选更新 worksheet hyperlink 的 `location`、`display`；未提供时保留原值。仅接受绝对 `file://` URI。
- 写出使用独立新输出路径，拒绝覆盖现有输出；源文件不修改。namespace-aware 解析，修改前完成关系映射，写后比对 ZIP 项顺序、数量、压缩方式及每项内容，只有指定 worksheet 和对应 rels 内容可变化；失败时移除本次创建的候选输出。含宏或数字签名的包按现有安全检查拒绝。
- 修正 A1 parser 以支持 `$A$1` 这类合法绝对单元格引用。
- `GPT修改记录/20261024_ooxml-external-hyperlink-patch.txt`：本记录。

## 状态与限制

- API 需要调用方先输出源工作簿，再指定一个不存在的独立候选输出路径；它不对原文件或已有候选做原位修改。
- 接受 URI 形式的绝对 `file://` target；路径中的空格、反斜杠和控制字符应由调用方先按 URI 规则编码或拒绝。
- 未在 Audit 真实生成结果或 Windows/麒麟/UOS 目标环境验证；Audit 仍需 cherry-pick 后重跑 S1-F01 的真实结果与 Python 对拍，确认链接显示值和解析目标行为。
