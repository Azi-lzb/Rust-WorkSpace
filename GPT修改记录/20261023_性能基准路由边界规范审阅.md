## 报告证据与规则对应

- **Rust-owned 普通值读取，XLSX，typed digest 契约**：same-range Calamine operation 中位数 132.100 ms、process wall 138.571 ms、RSS 17.3 MiB；full-sheet 为 134.064 ms、142.904 ms、18.1 MiB。规则据此只将 Calamine 列为契约匹配的 Rust reader 候选，不外推至其他输入格式、Python-owned 流程或不同值语义。
- **Python Direct OOXML 读取实现**：报告中的 `ooxml_external_prepare` 是具体 Python ZIP/XML 实现。same-range 与 full-sheet 的性能数字仅是其与报告契约下 Rust Calamine 的局部比较；不能概括为所有 Direct OOXML 实现。
- **Python reader 排序**：报告未做 Python `python-calamine` 与 Python Direct OOXML 的同进程端到端比较。规则要求 Python-owned 流程保留既有同契约验收路由；任何调整必须测完整调用链，计入进程启动/导入、序列化、传输、数据转换、IPC 和校验。
- **OOXML 专属元数据**：conditional-rule metadata 是单独请求，没有 Calamine 对等 API，故只记录专用适配器测量，不参与普通值 reader 排名，也不作为读取失败 fallback。
- **Rust 新建 XLSX writer**：规则将候选限定为 Rust-owned 结果、从零生成的纯数据 XLSX，并要求输出契约和预定义内存预算通过。30 万行 × 20 列同级压缩测试中，Rust `rust_xlsxwriter` 用时 8.729 s / RSS 1,376.7 MiB（纯数据），7.129 s / RSS 1,376.7 MiB（格式化）；对应 Python S5 为 17.406 s / 288.2 MiB、19.801 s / 354.0 MiB。该 RSS 是该规模/默认内存模式的观察值。
- **RSS 单位**：报告原始值 1,376.7 MiB 换算约为 1.34 GiB（十进制约 1.44 GB）。文档保留原始 MiB 数字并修正二进制单位换算，不将该结果变成通用阈值或任意大文件承诺。
- **Direct OOXML 写入**：`ooxml_s5` / `ooxml_s2` 是被测 Python 专用 writer。报告未比较 `rust_xlsxwriter` 与 Rust Direct OOXML writer，也未测试 constant-memory、既有工作簿编辑或通用 OOXML writer；这些能力必须单独实现和验收。
- **平台与格式**：报告环境为 Ubuntu/WSL2 x86_64、ext4、Release Rust，且测量输入为 XLSX。规则禁止外推到 Windows、麒麟、统信、XLS、XLSB 或未测平台/格式。
- **生产路由**：本次证据只进入候选评估。若考虑更改既有默认路由，先定义该功能的绝对节省时间、加速比例、峰值 RSS 上限和测试规模，再用同机、同输入、同契约的完整调用链测量。基准报告不自动更改生产默认。
