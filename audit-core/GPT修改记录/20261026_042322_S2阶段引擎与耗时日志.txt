# 2026-10-26 S2 阶段引擎与耗时日志

## 目的

让 S2 Rust CLI 与 Web 进度视图记录实际执行步骤、所用引擎和耗时。仅在 Audit 业务服务、CLI 和 Web bridge 加日志字段，不改共享 Excel-Core、Cargo 配置或原始前端 HTML。

## 涉及文件

- `audit-core/src/s2_service.rs`：为 S2 阶段提供引擎映射，并覆盖配置/读取、Rust 规则计算、XLSX 输出和读回校验。
- `audit-core/src/bin/open-data-audit.rs`：CLI 进度 JSON 增加引擎、总耗时与当前阶段耗时。
- `audit-core/src/web_bridge.rs`：GUI 进度状态增加引擎和阶段耗时；用户可见阶段标签显示当前引擎与阶段已运行时间。
- `audit-core/tests/s2_service_parity.rs`：断言 CLI 成功与失败路径的日志字段、引擎映射及累计耗时单调性。
- `audit-core/probe/reports/s2_progress_logging_windows_native_20261026.json`：记录合成回归及真实批次的脱敏日志证据。
- `audit-core/MIGRATION_INVENTORY.md`：更新 S2-F01 当前日志证据，整体状态仍为未验证。
- `audit-core/GPT修改记录/20261026_042322_S2阶段引擎与耗时日志.txt`：本记录。
