## 目的与变更

将 S5 的 V_EXT 来源选择从单来源扩展为多来源，复现 Python `SourceRepository._binding("external", ...)` 的显式来源、默认来源、业务回退、唯一来源回退和歧义行为。保留旧 `--external-source`/`--external-source-id` 用法；增加可重复 `--external-source-binding SOURCE_ID=BUSINESS=FILE` 与 `--default-external-source-id`。每个外部来源单独缓存动态布局与时序识别结果，所有绑定文件进入运行副本和哈希总账。

- `audit-core/src/s5_retrieval.rs`：增加外部来源绑定/快照和 Python 兼容的来源选择；按来源隔离布局与时序状态。
- `audit-core/src/bin/open-data-audit.rs`：接入外部绑定 CLI 参数、来源校验、开发者日志和多来源审核副本。
- `audit-core/tests/s5_previous_source_cli.rs`：覆盖业务回退、显式来源 ID、歧义和未匹配来源；保留旧单来源回归路径。
- `audit-core/tests/compare/compare_s5_outputs.py`：对比多个外部来源下 Python `AuditEngine.run` 与真实 Rust CLI 的完整输出，支持外部来源输入指纹和来源绑定。
- `audit-core/probe/reports/`：新增三份脱敏合成对拍摘要，分别记录业务回退、显式选择和歧义场景。
- `audit-core/MIGRATION_INVENTORY.md`：记录本切片证据与未验收边界。

没有修改共享 crates、根 Cargo 配置、`Cargo.lock`、`pytools-core/**`、`DEVELOPMENT_GOAL.md`、原 Python 项目或真实工作簿。
