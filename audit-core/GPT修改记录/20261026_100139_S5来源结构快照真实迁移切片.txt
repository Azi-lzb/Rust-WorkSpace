## 目的与修改文件

将 Python `SourceRepository` 的 HMAC 保护结构快照接入实际 `s5-audit-run` 读取、输出及运行总账。真实对拍发现，无命名结构区域时 Python 的 `openpyxl.max_row/max_column` 会计入带样式空白格，而 Rust 原先仅统计有值/公式的坐标，导致回退结构范围差异；Rust 现在复用共享 `excel_reader::read_xlsx_worksheet_extents` 获取只读 OOXML 范围，并覆盖样式空白坐标。

- `audit-core/src/s5_schema_snapshots.rs`：新增 S5 结构观察、HMAC 路径令牌、快照比较、失败状态和原子持久化。
- `audit-core/src/s5_scan.rs`：读取 XLSX/XLSM 的 OOXML 工作表 extent，令回退范围匹配 Python 工作表边界。
- `audit-core/src/s5_retrieval.rs`：从已执行的本期/上期取数索引收集结构观察。
- `audit-core/src/s5_outputs.rs`、`audit-core/src/bin/open-data-audit.rs`、`audit-core/src/lib.rs`：将快照事件接到输出阶段、CLI 总账和开发视图计数。
- `audit-core/tests/s5_outputs_parity.rs`：更新输出测试请求。
- `audit-core/tests/compare/compare_s5_outputs.py`：加入隔离密钥、Python 快照基线读取和结构事件对拍模式；导入只读源项目时禁止写入 pyc。
- `audit-core/probe/reports/s5_structure_snapshot_real_parity_windows_native_20261026.json`：脱敏真实对拍报告。
- `audit-core/MIGRATION_INVENTORY.md`：记录真实验证范围和未完成项。

未更改配置格式、VBA、Cargo workspace、共享 crates、根 Cargo 配置或版本号；原 Python 源项目、真实配置和真实工作簿均只读。
