## 目的与改动

把已有的条件格式 Issue 计算、模板功能映射和模板 Defined Names 计划接到真实 Audit CLI。`conditional-audit`、`conditional-audit-batch`、`conditional-audit-directory` 接受 `--template-workbook` 与可选 `--mapping-config`；未给配置时沿用源项目内置映射，模板指定后可使用 `OPEN_DATA_AUDIT_CONFIG` 作为环境配置来源。显式 `--scan-area` / `--structure-area` 继续覆盖模板计划。目录批量时排除模板/映射配置工作簿，并只从源工作簿推断期间。使用映射模板时，若匹配的条件格式 Defined Name 无法由共享 reader 解析，则停止并说明原因，避免意外扩大到规则 `AppliesTo` 范围。

Rust 通过共享 `excel_reader::read_defined_names` / `read_sheet_names` 读取命名区域，并以 `calamine+namespace_aware_ooxml` 完成值/元数据读取。对齐 Python 统计语义：没有条件格式规则的命名区域工作表不计入 Rust `scanned_cells`。普通和开发者日志记录映射来源、区域数量、reader、步骤状态及耗时；Python/Rust 对拍报告可选接收 Rust 进度事件并保留汇总。
