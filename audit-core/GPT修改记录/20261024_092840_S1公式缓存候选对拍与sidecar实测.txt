## 测试与证据

- WSL Ubuntu：`cargo build -p lo-convert --locked` 通过。
- Python AST 解析、`git diff --check` 通过。
- 合成候选默认模式通过：状态 `candidate_match_unverified`，0 差异；Rust 手动候选测试退出码 0。Rust 模板计划解析 4 个范围、16 个格、4 个公式、5 条批注；复制范围、未修改区域、元数据和计算标志差异均为 0；输入未改动。该结果不包含公式重算。
- Python 源实现缓存快照比较器合成检查通过：两个含同一公式的工作簿由源项目 `LibreOfficeCalculator.recalculate_many` 重算后，比较器读到 1 个公式及 2 个非空缓存值；`1e-15` 容差边界检查通过。
- 源项目 `LibreOfficeCalculator.recalculate_many` 对同一逻辑样本（A1=2、B1=3、C1=`SUM(A1:B1)`，并设置 `fullCalcOnLoad`/`forceFullCalc`）读回缓存值 5。
- Audit 分支现有 sidecar 合成重算运行以 `sidecar_exit_2` 失败，报告 `recalculation.status=failed`、1 个失败差异；因此未把该候选标为缓存对拍通过。额外隔离确认：LibreOffice 私有 profile 参数使用普通路径时进程失败，使用 `file://` URI 时能够生成文件。main 正协调共享 sidecar；其后续测试又观察到 URI 修正后的输出缓存仍为 0，尚未同步到 Audit 分支复测。
