## 目的与改动

将 Python base_audit.native.openpyxl_workbook.read_template 的 S1 公式规则发现和校验接入 Rust。新增 audit_core::s1_template_rules::load_s1_template_rule_plan 与 CLI open-data-audit s1-template-rules，覆盖命名区域公式规则和“审核规则”结构表两种形式。Rust 用共享 Calamine reader 读取值/公式文本，并用 namespace-aware OOXML 补充批注与 defined names；处理公式范围匹配、行列顺序、默认/批注规则编号、注释清理、规则重复、结果模式分类、结构区域与 Issue 提取范围。结构规则表校验必需表头、规则行和启用规则所引用的公式单元格。

CLI 默认返回不含规则内容的摘要；--include-rule-definitions 供工作流调用方选择接收完整内存定义。普通用户视图和开发者 JSON 视图均记录实际 reader、规则/范围数量与耗时。模板只读；不复制或修改工作簿、不执行公式重算。

另将 S1 映射默认回退条件对齐 Python：配置表存在其他有效 Audit 模块时不凭空生成未配置的公式/条件模块；没有可用 Audit 功能行时采用内置 S1 默认映射。
