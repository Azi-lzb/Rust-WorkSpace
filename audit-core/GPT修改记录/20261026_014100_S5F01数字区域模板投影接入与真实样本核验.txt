## 目的与变更

把 Python `numeric_scope.resolve_numeric_regions` / `project_numeric_regions` 的模板绑定数值区域投影接入 Rust S5 取数。改动仅在 Audit 业务层及测试，不修改共享 crate、根 Cargo 配置、原 Python 源码或真实工作簿。

- `audit-core/src/s5_numeric_scope.rs`：读取模板数字区域和结构命名区域；按 Python 的候选模板评分选择模板；用完整合并表头唯一投影数字区域；缓存每个工作表的投影；明确返回缺失/歧义错误，并在未匹配模板时保留既有全表兼容行为。
- `audit-core/src/s5_retrieval.rs`、`audit-core/src/s5_scan.rs`、`audit-core/src/lib.rs`：把当前/上期来源的投影区域用于配置路径定位，外部来源沿用原布局路线。
- `audit-core/src/bin/open-data-audit.rs`：`s5-audit-run` 增加 `--template-path` 与 `--template-dir`，默认目录遵循 `BASE_AUDIT_DATA_DIR` / 用户目录约定；日志区分模板投影与全表兼容回退，并报告实际引擎和耗时。
- `audit-core/tests/s5_previous_source_cli.rs`：覆盖自动目录匹配、显式模板优先、并列候选失败、默认目录、无模板兼容行为及投影范围限制。
- `audit-core/MIGRATION_INVENTORY.md`：记录此子切片的实现和边界。
- `audit-core/probe/reports/s5_numeric_scope_template_projection_real_windows_native_20261026.json`：保存脱敏真实坐标对拍和输入未变化证据。

未改变配置格式、VBA 或共享 Excel 能力；Audit 共享能力请求 #8 仍未解决。
