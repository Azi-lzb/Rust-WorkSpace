## 目的与迁移范围

将只读源函数 `base_audit.systems.s2_report_collection.config_check.check_s2_config` 和 `format_config_report` 迁移为 Audit Rust 实现，保留其报告字段、检查状态、错误/警告次序、中文提示及 UI 文本格式。运行时校验复用已迁移的 `s2_config::load_config`；读取继续使用共享 Calamine 适配器，不写回配置文件。

为复现 OpenPyXL 对日期格式单元格的解释，S2 配置读取改用共享 `read_value_columns_with_iso_dates`；`SheetValues` 增加 Calamine worksheet extent 字段供只读 sheet 统计使用。新增独立配置检查夹具、只读 Python 基线和 Rust 对拍报告。
