## 目的

承接 run 编排切片，移植 `outputs.write_run_outputs` 的单业务形态（审核副本、审核结果工作簿、运行总账），使 S5 运行的完整产出在 Rust 侧复现，并以文件级对拍验收。

## 修改文件

- `audit-core/src/s5_outputs.rs`：新增输出模块（run 目录结构、副本复制与 sha256 三方清单、审核结果工作簿写入（excel_writer/rust_xlsxwriter：表头/正文/J-K-L 专用格式、超链接、precision 数字格式、冻结/筛选/列宽像素接口/横向 A3 fitToPage/重复标题行、恒建空条件格式触发表）、运行总账稳定字段、safe_name/sha256/相对链接辅助）。
- `audit-core/src/s5_eval.rs`：`with_numeric_mode` 改按规则模式参数（Python 语义：excel_binary64 时 Decimal→round15 f64、blank 仅置 None 保种类）；`EvalError` 增加 evidence 字段与 `with_evidence`；Decimal28 增加 `is_integral`；新增 `parse_decimal28`。
- `audit-core/src/s5_retrieval.rs`：`retrieve` 拆出 `retrieve_inner` 并在失败时按 Python `retrieve` except 分支富化 evidence（function/sheet setdefault，不覆盖 cells）；`to_eval_error` 携带 evidence。
